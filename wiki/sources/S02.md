# S02 · RFC 9110 · HTTP Semantics

定義 HTTP 驗證標記、條件式請求及狀態碼。用於查對欄位的方向與 304 的內容。

[擷取紀錄](../../raw/S02.md) · [原文](https://www.rfc-editor.org/rfc/rfc9110.html)

<a id="section-8.8.3"></a>
## §8.8.3 ETag

ETag 是伺服器給資源回應的驗證標記。

[查閱原文段落](https://www.rfc-editor.org/rfc/rfc9110.html#section-8.8.3)

<a id="section-13.1.2"></a>
## §13.1.2 If-None-Match

GET 帶有快取中的舊 ETag 時，伺服器比對目前版本。命中時回 304。

[查閱原文段落](https://www.rfc-editor.org/rfc/rfc9110.html#section-13.1.2)

<a id="section-15.4.5"></a>
## §15.4.5 304 Not Modified

304 有回應標頭。資源內容由快取副本取得。

[查閱原文段落](https://www.rfc-editor.org/rfc/rfc9110.html#section-15.4.5)
