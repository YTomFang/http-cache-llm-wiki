# S03 · HTTP caching

用實例解釋快取、期限和驗證，也提醒瀏覽器重新整理可能改變請求行為。

<a id="fresh_and_stale_based_on_age"></a>
## Fresh and stale based on age

以已經過的時間解釋 fresh 和 stale。經過共享快取時，回應可能帶有 Age。

[查閱原文段落](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Caching#fresh_and_stale_based_on_age)

<a id="validation"></a>
## Validation

有驗證標記的舊副本仍可在驗證成功後使用。

[查閱原文段落](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Caching#validation)

<a id="reload"></a>
## Reload

按瀏覽器重新整理可能讓瀏覽器向伺服器要求驗證。

[查閱原文段落](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Caching#reload)

<a id="force_reload"></a>
## Force reload

強制重新整理可繞過現有快取。這和普通再次載入的情境不同。

[查閱原文段落](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Caching#force_reload)
