# K05 · 用 Chrome DevTools 檢查

怎麼在瀏覽器找出快取的線索？

搜尋詞：Network Chrome DevTools Headers Preserve log Disable cache 開發者 工具 實作

<a id="settings"></a>
## K05/settings

先開 Chrome DevTools 的 Network，勾 Preserve log 保留跨頁面紀錄。觀察正常快取時，讓 Disable cache 維持未勾選。

依據 [S05](../sources/S05.md#preserve-log)、[S05](../sources/S05.md#disable-cache)

<a id="inspect"></a>
## K05/inspect

選取同一個資源的請求，從 Headers 檢查狀態碼、Response Headers 的 Cache-Control／ETag，以及 Request Headers 是否帶 If-None-Match。

依據 [S05](../sources/S05.md#headers)、[S02](../sources/S02.md#section-13.1.2)
