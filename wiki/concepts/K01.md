# K01 · HTTP 快取與副本

快取存了什麼，能省下什麼？

搜尋詞：快取 副本 GET 200 HTTP 請求 回應 瀏覽器

<a id="copy"></a>
## K01/copy

瀏覽器會向伺服器請求圖片等資源。在示例中，首次成功的 GET 得到 200 OK 與圖片內容。HTTP 快取可以保留符合儲存條件的回應，供後續請求重用。

依據 [S01](../sources/S01.md#section-3)、[S04](../sources/S04.md#cache_update)

<a id="saving"></a>
## K01/saving

本機快取直接重用副本時可省下網路往返和資源傳輸。驗證後重用仍有網路往返，可省下再次傳送內容。

依據 [S01](../sources/S01.md#section-4.2)、[S04](../sources/S04.md#cache_update)
