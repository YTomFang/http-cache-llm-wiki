# K04 · Cache-Control 指令比較

可重用、先驗證、不可儲存有何差別？

搜尋詞：Cache-Control max-age no-cache no-store 指令 儲存

<a id="age"></a>
## K04/age

max-age=60 指定 60 秒的新鮮期限。在其他條件也符合時，新鮮的回應可直接重用。

依據 [S01](../sources/S01.md#section-4.2)、[S01](../sources/S01.md#section-5.2.2.1)

<a id="validate"></a>
## K04/validate

無參數的 no-cache 允許在其他儲存條件符合時保留副本，每次重用前都必須成功驗證。

依據 [S01](../sources/S01.md#section-3)、[S01](../sources/S01.md#section-5.2.2.4)

<a id="no-store"></a>
## K04/no-store

在此課的單一指令情境下，no-store 禁止 HTTP 快取儲存這次回應。

依據 [S01](../sources/S01.md#section-5.2.2.5)
